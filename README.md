# YouTube Video Summarizer using n8n

An AI-powered n8n automation workflow that extracts
YouTube video transcripts and generates a concise summary.

## Features

- YouTube video input
- Transcript extraction
- AI-powered summarization
- Automated workflow using n8n
- Structured summary output

## Workflow

YouTube Video
      ↓
Transcript
      ↓
AI Agent
      ↓
Summarization
      ↓
Final Output

## Technologies Used

- n8n
- AI / LLM
- YouTube
- Prompt Engineering
- JSON

## How to Use

1. Download the n8n workflow JSON file.
2. Open n8n.
3. Select Import from File.
4. Select the JSON workflow.
5. Configure your credentials.
6. Activate the workflow.
